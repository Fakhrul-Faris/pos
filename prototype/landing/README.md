# Miki Landing Prototype

Editorial fintech landing page for the Miki multi-vertical hub homepage.

**Style:** [Jeton design language](../../docs/design/themes/jeton-design.md) adapted with Miki green (`#38CE87`) as the signal accent.

## Run

```bash
cd prototype/landing
npm install
npm run dev
```

Open the URL shown in the terminal (default `http://localhost:5173`).

## Scope

Hub homepage (`/`) prototype only — promo banner, hero, business picker, three surfaces, payments, outcomes, FAQ, waitlist stub, footer. No pricing page or section.

Copy sourced from `docs/design/marketing-copy.md` and `docs/design/web-structure.md`.
